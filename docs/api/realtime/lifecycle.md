# `pydantic_ai.realtime.lifecycle`

The lifecycle events a [`RealtimeConnection`][pydantic_ai.realtime.codec.RealtimeConnection] yields with its
[codec events](codec.md), for implementing a realtime provider: which response, spoken turn, and input each
codec event is about. Most users only need the session-level API in [`pydantic_ai.realtime`](../realtime.md).

::: pydantic_ai.realtime.lifecycle
